# 🛒 Blinkit Sales Data Analytics Dashboard

## 📊 Project Overview
This project focuses on analyzing Blinkit sales data to uncover key business insights using Power BI. The dashboard helps in understanding sales performance, customer preferences, and outlet-level analysis for better decision-making.

---

## 🎯 Objectives
- Analyze total sales and revenue trends
- Understand customer ratings and product performance
- Compare outlet performance by size and location
- Identify top-performing product categories
- Enable data-driven business decisions

---

## 📁 Dataset Information
- Total Records: 8,500+
- Fields Included:
  - Item Type
  - Outlet Type
  - Outlet Size
  - Outlet Location (Tier 1, 2, 3)
  - Sales
  - Ratings

---

## 🛠️ Tools & Technologies
- Power BI (Dashboard & Visualization)
- Excel (Data Cleaning)
- SQL (Concepts used for querying/filtering)
- Python (optional for preprocessing)

---

## 📈 Dashboard Features
- 💰 Total Sales: $1.2M+
- 📦 Total Items: 8,500+
- ⭐ Average Rating Analysis
- 🏬 Outlet Size Comparison (Small, Medium, High)
- 📍 Location-based Analysis (Tier 1, 2, 3)
- 🍎 Item Category Performance

---

## 🔍 Key Insights
- Tier 1 outlets generate the highest revenue
- Medium-sized outlets perform better overall
- Certain categories (like snacks & beverages) dominate sales
- Customer ratings impact product sales trends

---

## 📊 Business Impact
- Helps businesses optimize inventory
- Improves decision-making using data
- Identifies high-performing outlets and products
- Supports sales and marketing strategies
